# Glitch Kids : Utils Packages

- file-system.gk : Adapter of `node:fs`, `node:path` & `fast-glob`.
- config-reader.gk : Utility package to read "glitchkids.config.js/ts" files.

## Installation

**pnpm is recommended !**

#### oop-toolbox.gk

```bash
  pnpm add glitchkids/utils#path:/dist/oop-toolbox.gk
```

#### file-system.gk

```bash
  pnpm add glitchkids/utils#path:/dist/file-system.gk
```

#### config-reader.gk

```bash
  pnpm add glitchkids/utils#path:/dist/config-reader.gk
```
