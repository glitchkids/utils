# Glitch Kids : Utils Packages

**pnpm is recommended !**

# toolbox.gk

This package is a toolbox for Glitch Kids Development Workflow.

#### Installation

```bash
  pnpm add glitchkids/utils#path:/dist/toolbox.gk
```

# file-system.gk

Adapter of `node:fs`, `node:path` & `fast-glob`

#### Installation

```bash
  pnpm add glitchkids/utils#path:/dist/file-system.gk
```

# config-reader.gk

Utility package to read `glitchkids.config.js/ts` files.

#### Installation

```bash
  pnpm add glitchkids/utils#path:/dist/config-reader.gk
```
